# SQL Practice 🗃️

A hands-on SQL learning repository where I practise database querying step by step, from basic statements to interview-style problems and advanced SQL concepts.

## 📁 Repository Structure

| Folder | Contents |
|---|---|
| [**Notes/**](./Notes/) | SQL topic roadmap, concepts, and revision notes |
| [**Practice/**](./Practice/) | SQL scripts, exercises, and interview questions |

## 📚 Topics Covered

- SQL basics: `SELECT`, `DISTINCT`, and aliases
- Filtering and sorting with `WHERE` and `ORDER BY`
- Comparison, logical, and other operators
- Aggregate functions
- `GROUP BY` and `HAVING`
- Joins
- `UNION`
- Subqueries
- `CASE WHEN`
- Views and common table expressions (CTEs)
- SQL interview practice
- Window functions (in progress)

## 🚀 How to Practise

1. Open a script in [`Practice/`](./Practice/).
2. Run it in a SQL database environment compatible with the syntax used in the file.
3. Change the queries and try solving the exercises yourself.
4. Review the topic roadmap in [`Notes/`](./Notes/).

## 🎯 Learning Goal

Build a solid SQL foundation for Data Analysis and Data Science, while developing problem-solving skills for technical interviews.
